# Conformational ensembles from CREST

Confromational ensembles are presnted in the form of ``conformers.xyz`` files. Due to the large size of the ``TiOnBu4_confromers.xyz`` file, it was archived and splitted into parts. Download all parts into the same directory, then reconstruct it:

```bash
cat TiOnBu4_conformers.xyz.tar.gz.part-* > TiOnBu4_conformers.xyz.tar.gz
tar -xvf TiOnBu4_conformers.xyz.tar.gz
```

``TiOsBu4_conformers.xyz`` was also archived and should be retrieved:

```bash
tar -xvf TiOnBu4_conformers.xyz.tar.gz
```
